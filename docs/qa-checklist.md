# Приёмка интерфейса: что проверено и чем

Дизайн-система задаёт чек-лист из десяти проверок на экран. Здесь —
результат прогона по всем семи экранам (шесть продуктовых плюс
служебный стайлгайд) и способ, которым проверялось: без способа
результат нельзя повторить, а значит нельзя и доверять.

Дата прогона: 07.09.2026. Проверка автоматическая, через управление
браузером, — не «посмотрел глазами».

---

## Адаптивность · пройдено

Четыре точки перелома системы: 390 / 768 / 1024 / 1440.

| Что проверялось | Как | Результат |
|---|---|---|
| Горизонтальная прокрутка страницы | `scrollWidth` против `clientWidth` на каждом экране | нет ни на одной ширине |
| Элементы шире экрана | обход всех узлов, сравнение `getBoundingClientRect().right` с шириной окна | нет, кроме собственных прокруток таблиц и навигации |
| Таблицы | горизонтальная прокрутка внутри обёртки, липкая первая колонка | работает |
| Графики | отрисовка канваса на всех ширинах | рисуются |

**Исправлено по ходу:** сетки `minmax(380px, 1fr)` распирали страницу на
375px — заменены на `minmax(min(380px, 100%), 1fr)`. Переключатель
периодов из четырёх кнопок не помещался в 375px — получил собственную
прокрутку.

---

## Касание · пройдено

Проверялось при эмуляции мобильного устройства (`pointer: coarse`,
`hasTouch`), а не по ширине окна: планшет шириной 1024 — это палец, а
узкое окно на настольном компьютере — курсор.

Найдено 76 целей меньше 44px: навигация 32, сегменты переключателя 28,
кнопки 40/32/28, поля 40, логотип 20. Добавлен слой
`src/styles/touch.css`, поднимающий цели до 44px при грубом указателе.
Повторный прогон: **целей меньше 44px не осталось ни на одном экране**.

Отдельно: крестик снятия фильтра — самая мелкая цель системы — получил
невидимое поле нажатия 44×44, сам чип при этом не вырос.

---

## Клавиатура · пройдено

Проход `Tab` по экрану «Вакансии», 22 остановки:

- порядок совпадает с визуальным: логотип → навигация → главная кнопка
  → фильтры слева направо → флажок → строки таблицы;
- обводка фокуса видна на всех остановках (кольцо 3px по
  `:focus-visible`, проверено сравнением тени до и после фокуса);
- строки таблицы доступны с клавиатуры и открывают панель по Enter.

**Автокомплит:** стрелки перебирают подсказки, Enter применяет, Escape
закрывает. Исправлено: после выбора список открывался заново, потому что
изменение значения запускало новый запрос.

**Диалог подтверждения.** Найден настоящий дефект: диалог не забирал
фокус, и пользователь клавиатуры оставался «под» модалкой. Добавлены
автофокус на поле, ловушка `Tab` внутри диалога и возврат фокуса на
кнопку, с которой диалог открыли. Проверено: фокус уходит в поле, `Tab`
крутится внутри, Escape закрывает, фокус возвращается на «Запустить
сбор».

## Состояния данных · пройдено

| Состояние | Как вызывалось | Результат |
|---|---|---|
| Пусто | фильтр, под который не подходит ни одна вакансия | «Ничего не найдено» + кнопка сброса |
| Ошибка | обрыв всех запросов к API | «Список не загружен» + причина + «Повторить» |
| Загрузка | скелетоны рамки графика и плиток KPI | каркас держит высоту, страница не дёргается |
| Мало данных | выборка меньше пяти | пометка вместо числа |

Сообщения об ошибках говорят, что делать («Сервер не отвечает.
Проверьте, запущено ли приложение»), а не что произошло внутри.

## Печать · пройдено

Проверено эмуляцией `media: print`:

- фон страницы становится белым;
- прокручиваемые таблицы разворачиваются целиком (`overflow: visible`);
- шапка таблицы повторяется на каждом листе (`table-header-group`);
- кнопки и прочий интерактив скрыты.

Не проверялось на физическом принтере — только правила CSS.

## Браузеры · пройдено

Прогон выполнен в трёх движках на ширинах 390 / 768 / 1440, по семь
экранов в каждом: Chromium (через управление браузером), **Firefox 155**
и **WebKit 26.6** — движок Safari. Скрипт прогона:
проверяет горизонтальную прокрутку, элементы шире окна, загрузку
гарнитуры, табличные цифры, поддержку `:has()` и `dvh`, отрисовку
графиков и ошибки консоли.

**Результат: 0 проблемных экранов в каждом движке.** Гарнитура Geologica
грузится везде, табличные цифры работают, `:has()` и `dvh` поддержаны
всеми тремя.

**Найдено и исправлено при первом прогоне в Firefox:** график динамики
падал с `TypeError: this._fn is not a function`. Причина — столбец
незакрытого периода залит штриховкой, то есть `CanvasPattern`, а
Chart.js пытался анимировать его как цвет. Анимация цветов отключена в
теме (`Chart.defaults.animations.colors = false`), анимация размеров
осталась. В Chromium ошибка не воспроизводилась — она нашлась только
потому, что прогон повторили в другом движке.

Свойства, за которыми стоит следить при обновлении:

| Свойство | Где | Состояние |
|---|---|---|
| `:has()` | кольцо фокуса на обёртке поля | поддержано во всех трёх движках |
| `dvh` | высота оболочки, модалки, нижнего листа | поддержано; рядом оставлен `vh` |
| `env(safe-area-inset-bottom)` | нижний лист, тосты, кнопки модалки | игнорируется там, где не поддержан |
| `scrollbar-width` | навигация, переключатель | добавлен `::-webkit-scrollbar` для Safari до 18.2 |
| `mask-image` | затухание края навигации | добавлен `-webkit-` префикс |

## Инлайн-баннеры · пройдено

Сообщение о состоянии экрана живёт на экране, а не в углу с тостами, и
не исчезает по таймеру: условие, которое его вызвало, никуда не делось.
Четыре вида, все проверены на реальных данных.

| Вид | Где | Проверено |
|---|---|---|
| info | «Данные собраны 4 дня назад» + «Собрать» | появляется, когда сбор старше 48 часов |
| info | «Сравнение с прошлым периодом не показывается» | стоит под плитками с прочерками |
| filtered | «Выборка сужена: 307 из 684 вакансий» | появляется с фильтром, исчезает по «Сбросить» |
| filtered | «Зарплатные числа считаются по 410 из 684» | на аналитике, до самих чисел |
| warning | «Следующий сбор перезапишет базу целиком» | появляется при выключении дописывания, снимается кнопкой «Включить дописывание» |
| error | «Сбор прервался» + «Повторить сбор» | показывается, когда прошлый запуск закончился ошибкой |
| info | «Числа относятся к справочнику, а не к вашей базе» | постоянно на экране «Профессии» |

Жёлтый маркерный фон использован ровно там, где разрешает система: он
помечает, что все числа на экране считаны по суженной выборке. Во всех
остальных видах фон спокойный, цвет несёт только знак.

## Где интерфейс расходится с конспектом макета

- **Колонка «Опубликована» в списке вакансий** (Э2, 09.09.2026). В
  `design/spec/Экран Вакансии.md` таблица из пяти колонок; в коде их
  шесть. Колонка добавлена сознательно: при сортировке «сначала новые»
  порядок нельзя было проверить, не открывая карточку. Новых
  компонентов не заведено — это ячейка `BvTable`, срок считает общая
  `timeAgo`, название взято из панели вакансии («Опубликована»), где
  оно уже стояло. Конспект — снимок макета, править его задним числом
  не стали; расхождение записано здесь, чтобы при следующей сверке оно
  не читалось как случайное.

## Закрыто из требований дизайн-системы

- **`BvSegmented` подтягивает активный сегмент в видимую часть**
  (S1, 09.09.2026). На узком экране переключатель прокручивается внутри
  себя, и сегмент, не поместившийся в ширину, оставался за краем:
  выбранным оказывался невидимый пункт — человек видел три невыбранные
  вкладки, а данные приходили от четвёртой. Поймано на 390 с четырьмя
  категориями навыков.

- **`BvBarList` печатает не только счётчики** (E5, 09.09.2026). Спека
  графиков описывает подпись вида «медиана по 47 вакансиям», но список
  умел показывать только число и долю целого. Добавлены `format`
  (как напечатать значение — деньги вместо счётчика) и `note` у строки
  (что стоит справа, когда доли нет). Прежние потребители не тронуты:
  без этих полей поведение прежнее.

- **Выключенное состояние `BvSelect`** (К3‑7, 09.09.2026). Спека «Формы»
  описывает состояние «Выключено» с объяснением рядом («Недоступно, пока
  идёт сбор»), но в коде селект его не поддерживал: проп уходил в
  атрибуты обёртки, а поле оставалось активным. Добавлено в примитив;
  первым им пользуется выбор валюты на аналитике, который в рублёвом
  виде ни на что не влияет.

## Что дизайн-система требует, а интерфейс пока не делает

- **Слой аккаунта** (вход, кабинет, доступ по ссылке) не собран —
  в бэкенде нет ни авторизации, ни пользователей.

Закрыто позже основного переноса: онбординг из трёх шагов, слой тостов,
карточка вакансии целиком, инлайн-баннеры, цели нажатия 44px, нижние
листы, фокус-ловушка в оверлеях.
